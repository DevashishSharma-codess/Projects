## 💻 Overview

**EnactOn** is a web application engineered with **React 19**, **Vite 8**, **Three.js**, **Framer Motion**, **GSAP**, **Tailwind CSS v4**, and **Lenis Smooth Scroll**. Designed for high visual impact and smooth 60 FPS performance, it presents agency capabilities, interactive 3D elements, performance diagnostics, and case study showcases.

---

## ✨ Key Features

- 🌀 **Interactive 3D WebGL Canvas**: Powered by `three` and `detect-gpu` for hardware-adaptive 3D rendering.
- ⚡ **GSAP & Framer Motion Animations**: Micro-interactions, scroll-driven triggers, parallax effects, and smooth layout transitions.
- 📜 **Lenis Smooth Scrolling**: Ultra-smooth inertia scrolling experience.
- 📱 **Fully Responsive Layout**: Built with Tailwind CSS v4 and flex/grid responsive breakpoints.
- 📊 **Lighthouse Performance Benchmarked**: Audited for Core Web Vitals, accessibility, and high performance score.

---

## 🛠️ Tech Stack & Performance

- **Frontend Framework**: React 19 (`react` ^19.2.8 / `react-dom` ^19.2.8)
- **Build Tool**: Vite 8 (`vite` ^8.2.0)
- **3D Graphics**: Three.js (`three` ^0.185.1) + Detect GPU (`detect-gpu` ^5.0.70)
- **Animations & Smooth Scroll**: Framer Motion (`framer-motion` ^13.0.0), GSAP (`gsap` ^3.15.0), Lenis (`lenis` ^1.3.26)
- **Styling**: Tailwind CSS v4 (`tailwindcss` ^4.3.3 / `@tailwindcss/vite` ^4.3.3)
- **Icons**: Lucide React (`lucide-react` ^1.31.0)
- **Performance Diagnostics**: Web Vitals (`web-vitals` ^6.1.0)

## 🚀 Getting Started & Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/enacton-interns/Devashish-Repo.git
   cd EnactOn
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```

5. **Preview Production Build**:
   ```bash
   npm run preview
   ```
